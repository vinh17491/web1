# ZinZin Portfolio

Personal software engineering portfolio for @vinh17491.

## Purpose

This repository hosts a lightweight portfolio focused on:
- Software engineering profile and technical stack
- Featured projects and engineering outcomes
- Project result / screenshot gallery
- Direct GitHub and contact links

## Run locally

Open `index.html` directly, or serve the folder with any static server.

Example:

```bash
python -m http.server 8000
```

Then open http://localhost:8000.

## Add project screenshots

Put images inside:

```text
assets/projects/
```

The site is structured so real screenshots can be added without changing the overall layout.

## Deployment

This site has no build step and is compatible with GitHub Pages using the repository root on the `main` branch.
